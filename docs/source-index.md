# Spartan Drill source index

JavaScript under `js/` is shipped as readable source. The web loader assembles these files into one closure at runtime. Use the original paths below for `engine.patches`. Generated bundles and old names shown in comments are outside the patch target list.

## Engine patch targets

The default script order is the order of the JavaScript rows here. `js/mod-game.js` and its stylesheet are loaded by v3 conversions.

| File | Responsibility and search terms |
| --- | --- |
| [index.html](../index.html) | Multiplayer and Zombies shell. Match setup, HUD, settings, pause menu, and results markup. `sd-game-loader` loads the script list and hashes the normal web build. |
| [style.css](../style.css) | Shared game presentation. Search the component ID or class from HTML or JavaScript to find matching rules. Older sections and expanded newer rules coexist. |
| [js/stormfront-data.js](../js/stormfront-data.js) | Shared Stormfront content, catalog, pack validation, progression definitions, and grid routing. Find `StormfrontData`, `content`, `applyPacks`. |
| [js/world.js](../js/world.js) | Renderer and post-processing, weapons table, match lifecycle, input dispatch, collision queries, arena and voxel map builders. Find `LX.render`, `W`, `buildMap`, `mv`, `castW`, `shoot`, `startGame`, `gameFrame`. |
| [js/systems.js](../js/systems.js) | Combat effects, weapons and humanoid rigs, bot AI, locomotion, team modes, sky and lighting. Find `endGame`, `buildGun`, `mkHuman`, `phys`, `updBots`, `pvpTick`, `gfxTick`. |
| [js/net-safety.js](../js/net-safety.js) | Network transport configuration, packet-validation helpers, peer/session safeguards, and rate limiting. |
| [js/interface.js](../js/interface.js) | Multiplayer and party messaging, main and pause menus, results sequence, controls, touch, gamepad, VR, navigation grids, profile and unlock UI. Find `onMsg`, `showPause`, `navBuild`, `kbDown`, `actInteract`, `finStart`. |
| [js/menus.js](../js/menus.js) | Loadout and cosmetics, practice, One in the Chamber, party and lobby panels, title and mode menus, Stormfront entry. Find `OI`, `openGameParty`, `setApp`. |
| [js/zombies.js](../js/zombies.js) | Zombies rounds, enemies, interactions, perks, Pack-a-Punch, London, Hollow Estate, the one-room map, Jovian Terminus, and their in-engine quests. Find `zStart`, `zDamage`, `zomTick`, `lonBuild`, `jupiterQuestStart`. |
| [js/mods.js](../js/mods.js) | v1–v3 validation, JSON schema generator, installed pack catalog and save bridge, conversion assembly, native map and playlist installation, Mods dialog. Find `conversionFormat`, `modKit`, `prepareEngine`, `conversionGuest`, `modInstall`. |
| [js/streaks.js](../js/streaks.js) | Scorestreaks, weapon feel and feedback, challenges, match-integrity checks. Find `SK`, `useStreak`, `chEv`. |
| [js/mod-game.js](../js/mod-game.js) | Stable v3 scripting adapter. Entity snapshots, lifecycle hooks, runtime map objects, bot controls, vehicle simulation, and scripted UI. Treat the published `SpartanMod.game` surface as the contract. |
| [js/mod-game.css](../js/mod-game.css) | v3 scripted HUD controls, menus, toasts, and module-load errors. |
| [assets/classic-crossroads.webp](../assets/classic-crossroads.webp) | Classic Crossroads map preview. |
| [assets/shardworks.webp](../assets/shardworks.webp) | Shardworks map preview. |
| [assets/earth-orbit.js](../assets/earth-orbit.js) | Embedded Earth texture for the Jovian Terminus departure cinematic. |
| [assets/stormfront.webp](../assets/stormfront.webp) | Stormfront artwork used by the title menu. |

## Other shipped files

| File | Responsibility |
| --- | --- |
| [conversion.html](../conversion.html) | Trusted conversion host page with the sandboxed frame and return link. It assembles packs via `js/mods.js`. |
| [stormfront.html](../stormfront.html) | Standalone Stormfront entry point. |
| [js/engine-source.js](../js/engine-source.js) | Generated source snapshot for automatic local engine launches. Edit the original files above to change the snapshot. |
| [tools/build-engine-source.cjs](../tools/build-engine-source.cjs) | Regenerates the snapshot from the game source and assets. Run `node tools/build-engine-source.cjs --check` to verify it. |
| [js/stormfront.js](../js/stormfront.js) | Stormfront renderer, systems, campaign, cooperative state, menus, audio, and missions. Stormfront content packs use the `stormfront` manifest section. |
| [relay.py](../relay.py) | Optional Python companion for LAN game hosting and room traffic. |
| [README.md](../README.md) | Player handbook, installation, controls, and gameplay modes. |
| [spartan-drill-mod-v3.schema.json](../spartan-drill-mod-v3.schema.json) | Full JSON Schema generated by `conversionFormat.authorSchema(modKit.schema)`. |
| [docs/modding-api.md](modding-api.md) | Scripting reference, examples, units, limits, and compatibility information. |
| [docs/spartan-mod.d.ts](spartan-mod.d.ts) | Ambient TypeScript definitions for the public runtime. |
| [docs/source-index.md](source-index.md) | This file and patch-target map. |
| [examples/vehicle-workshop.sdmod](../examples/vehicle-workshop.sdmod) | Installable v3 pack demonstrating module loading, keybinds, HUD and pause entries, custom vehicles, and the NPC toggle. |

The macOS `.DS_Store` file is Finder metadata. The engine does not load it.
